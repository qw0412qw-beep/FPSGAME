# 프로젝트 이름 (라스트 바스티온:제로)
최후의 도시에서 몰려드는 좀비들의 습격을 막아내는 게임

---

## 개요

**장르** : 3인, 슈팅, 생존, 좀비 아포칼립스

**엔진** : Unreal Engine 5.4

**플레이어 수** : 1인 싱글플레이

---

## 플레이 목표

일정 시간동안 사방에서 몰려드는 좀비들을 목표 수 만큼 퇴치해야 한다.

---

## 진행 방식

1. 기본 아이템을 지급받는다.
   
        ↓
  
2. 준비 시간 동안 전투를 준비한다.

        ↓
  
3. 준비 시간이 끝나고 퇴치 목표 카운트를 확인할 수 있고 좀비들이 몰려든다.

        ↓
  
4. 몰려드는 좀비를 목표 카운트 수 만큼 퇴치한다.

        ↓
  
5. 라운드 생존

        ↓
  
6. 다시 일정 시간 동안 준비 시간이 부여된다.

        ↓
   
7. 2~6까지 라운드 수 만큼 반복한다.

        ↓
  
8. 최종 생존

---

## 조작

플레이어 이동 : W A S D

시점 이동 : Mouse

줌(조준) : Right Click 

사격 : Left Click

재장전 : R

점프 : SPACE

아이템 사용 : F

---

## 주요 기능

플레이어는 정해진 맵 범위 내에서 이동이 가능

* 회복 아이템 사용

* 캐릭터의 현재 상태 (HP, 총알 등) 확인 가능
